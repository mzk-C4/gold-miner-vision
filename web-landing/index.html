.hpp services/GestureData.hpp 手势数据模型 — 三种手势态 + 融合指令 
enum class GestureType {
    OPEN_PALM,  // 张开手掌 → 瞄准模式：钩子连续摆动
    FIST,       // 握拳     → 释放钩子
    UNKNOWN     // 无手势   → 维持当前状态
};

struct GestureResult {
    GestureType gesture = GestureType::UNKNOWN;
    float angle       = 0.0f;    // 钩子角度 [-65, +65]
    float confidence  = 0.0f;    // 置信度 [0, 1]
    bool  isValid     = false;   // 是否有效
    bool  isStable    = false;   // 时域去抖通过
    bool  isLocked    = false;   // 状态锁定（连续3帧）
    std::string source;          // "local" / "cloud" / "fusion"
};

struct GestureCommand {
    bool  shouldReleaseHook   = false;  // 是否释放钩子
    bool  shouldDetonateBomb  = false;  // 是否引爆炸药
    float targetAngle         = 0.0f;   // 钩子目标角度
    bool  isValid             = false;  // 指令有效性
};
.hpp services/IGestureRecognizer.hpp 策略模式接口 — 本地/云端识别器均实现此接口 
class IGestureRecognizer {
public:
    using ResultCallback = std::function<void(const GestureResult&)>;

    virtual ~IGestureRecognizer() = default;

    /// 启动识别器（初始化资源、打开摄像头/建立连接）
    virtual bool start() = 0;

    /// 停止识别器（释放资源）
    virtual void stop() = 0;

    /// 注册结果回调（在 start 之前设置）
    virtual void setCallback(ResultCallback cb) = 0;

    /// 推送一帧 JPEG 图像（异步，立即返回）
    virtual void pushFrame(const std::vector<uint8_t>& jpegData) = 0;

    virtual bool isRunning() const = 0;
    virtual const char* name() const = 0;
};

class LocalGestureRecognizer : public IGestureRecognizer {

    void setCallback(ResultCallback cb) override;
    void pushFrame(...) override; // no-op: Server自行取帧
    bool isRunning() const override;
    const char* name() const override { return "local"; }

private:
    void pollThread();  // HTTP 轮询线程
    std::thread _thread;
    std::atomic<bool> _running{false};
    ResultCallback _callback;
    std::string _lastGesture;
    int _stableCount = 0;

    // 精度策略（GestureServer 已实现）：
    // 策略1 — 多模态关键点融合（凸包指尖+轮廓距离）
    // 策略2 — 指尖距离算法（替代置信度阈值）
    // 策略3 — 时域平滑（EMA角度+3帧状态锁定）
    // 策略4 — 动态亮度自适应（HSV阈值调整）
};

.hpp services/GestureFusion.hpp 双通道融合核心 — 本地高频 + 云端低频，安全优先 
class GestureFusion {
public:
    using CommandCallback = std::function<void(const GestureCommand&)>;
    static GestureFusion* getInstance();

    bool initialize(const std::string& cloudEndpointId,
                     const std::string& cloudApiKey);
    void shutdown();
    void setCommandCallback(CommandCallback cb);
    GestureCommand tick(float dt);  // Game::update() 每帧调用
    void pushPreviewFrame(const std::vector<uint8_t>& jpegData);

private:
    // 融合逻辑：
    //   OPEN_PALM → 本地角度直接输出（连续瞄准）
    //   FIST 锁定 → 本地+云端双重确认才释放钩子
    //   云端超时  → 降级：仅信任本地结果
    //   云端本地不一致 → 放弃本次触发（安全优先）

    GestureResult _latestLocal;   std::mutex _localMutex;
    GestureResult _latestCloud;   std::mutex _cloudMutex;
    std::atomic<bool> _fistPendingCloud{false};
    float _gameAngle = 0.0f;      // 游戏级角度平滑
    float _releaseCooldown = 0.0f; // 0.8s 释放冷却
    float _fistHoldTime = 0.0f;    // 长握拳 >1.5s → 炸弹
};

Gesture Control

手势控制

四种手势映射游戏操作，AI 视觉实时识别你的每一个动作

🖐️

张开手掌

瞄准模式 · 钩子摆动

将手掌完全张开面对摄像头，识别器检测五指伸展状态。钩子进入连续摆动模式，在 -65° 至 +65° 之间来回扫描，让你观察矿洞中矿物的分布位置，确定最佳抓取时机。

技术实现：OpenCV 凸包算法检测指尖数量 ≥4，轮廓面积 / 凸包面积比值判定手指分离程度。云端二次确认后锁定为 OPEN_PALM 状态。

✊

握拳

释放钩子 · 抓取矿物

快速握紧拳头，识别器检测指尖数量骤减至 0~1 个。钩子立即沿当前角度射出，接触矿物后自动抓取并回收。回收速度取决于矿物重量，越重的矿物回收越慢。

技术实现：本地识别器检测到 FIST 后进入"待确认"状态，触发云端 AI 请求。仅当云端置信度 > 0.85 或超时降级时才执行释放，防止误触发。

👋

左右倾斜

控制方向 · 精确瞄准

手部自然左右倾斜，识别器通过分析手部轮廓的几何中心偏移计算倾斜角度，映射到钩子摆动范围 [-65°, +65°]，实现精确瞄准目标矿物。

技术实现：计算手部轮廓的 Hu 矩获取主轴方向角，经 EMA (指数移动平均) 平滑处理消除手抖噪声，输出连续稳定的角度值。

💣

长握拳 (1.5s+)

引爆炸药 · 舍弃重物

当钩子已抓取到矿物正在回收时，持续握拳超过 1.5 秒触发炸药。炸毁当前钩住的物品，钩子立即回收。适用于误抓石头等低价值重物时紧急止损。

技术实现：GestureFusion 内部维护 _fistHoldTime 计时器，每帧累加 dt。超过 1.5s 阈值且玩家已购买炸药道具时，下发 shouldDetonateBomb 指令。

Dual Mode

双模式识别

本地 CV + 云端 AI，灵活切换，确保任何环境都能游玩

Local CV

🟢 本地 CV 模式

基于 OpenCV 颜色阈值的手势识别方案，直接在本地进行图像处理和分类，无需网络连接即可流畅运行。

  • ✓ 零网络延迟 — 识别在本地完成，帧率可达 30fps
  • ✓ 完全离线 — 不依赖任何外部服务，随时随地可用
  • ✓ 低资源占用 — CPU 占用率 < 15%，不影响游戏性能
  • ✓ 端到端延迟 < 50ms — 从采集到判定的瞬时反馈
  • ⚠ 需要彩色手套辅助 — 推荐佩戴纯色手套提高 HSV 分割精度
  • ⚠ 对极端光照敏感 — 光线过暗或过亮时需调整摄像头参数
Cloud AI

🟣 云端 AI 模式

调用远程 AI 视觉模型接口，利用深度学习进行高精度手势识别，无需任何辅助标记物即可准确分类。

  • ✓ 裸手识别 — 无需佩戴手套或任何标记物
  • ✓ 准确率 > 95% — 深度学习模型高精度分类
  • ✓ 复杂手势支持 — 可识别多种细微手势变化
  • ✓ 光照鲁棒性 — 对不同光照条件适应力强
  • ⚠ 需要网络连接 — 依赖稳定的互联网环境
  • ⚠ 单次延迟 200~800ms — 低频触发策略避免影响体验

Highlights

项目亮点

C++ 课程大作业中的技术亮点与设计模式应用

3

设计模式

单例模式管理全局识别器实例；策略模式通过 IGestureRecognizer 接口抽象本地/云端两种识别策略，支持运行时切换；观察者模式通过 Callback 机制解耦识别结果与游戏逻辑。

5

精度优化策略

① 多模态关键点融合 (凸包指尖+轮廓距离) ② 指尖距离算法替代固定阈值 ③ EMA 时域平滑 + 3帧状态锁定防抖 ④ 动态 HSV 亮度自适应 ⑤ 增强 Prompt 引导云端模型精准分类。

8

矿物种类

3 种金块 (小/中/大)、3 种石头 (小/中/大)、钻石、宝藏袋共 8 种矿物。每种矿物拥有独立的价值、重量、回收速度属性，由 LevelLoader 从 JSON 配置动态加载各关卡分布。

5

游戏关卡

难度层层递进的 5 大关卡。早期以金块为主帮助玩家熟悉操作；中期引入钻石和宝藏袋增加策略深度；后期石头激增、时间收紧，考验精准操作与道具规划。
