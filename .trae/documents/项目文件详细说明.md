# 黄金矿工项目 - 详细文件说明

---

## 项目结构总览

```
cocos2d-proj/
├── Classes/              # C++源代码（核心逻辑）
├── GestureServer/        # 独立手势识别服务
├── Resources/            # 游戏资源（图片、音乐、CSB）
├── proj.win32/           # Windows工程文件
├── CMakeLists.txt        # CMake构建配置
├── package.json          # Cocos Creator项目信息
└── settings.json         # Cocos Creator设置
```

---

## 一、Classes/ - 游戏核心源代码

### 1.1 MainScene/ - 主场景相关类

| 文件 | 功能说明 | 核心类 |
|------|---------|--------|
| **Game.hpp** / **Game.cpp** | **游戏主逻辑核心**！处理钩子摇摆、碰撞检测、分数计算、手势输入 | Game (继承Layer) |
| **MainRoot.hpp** / **MainRoot.cpp** | 游戏主菜单场景，提供"开始游戏"、"商店"等按钮 | MainRoot |
| **Shop.hpp** / **Shop.cpp** | 商店系统，允许玩家用金币购买道具（炸弹、力量药水、钻石升值书等） | Shop |
| **Pause.hpp** / **Pause.cpp** | 暂停界面，暂停游戏时显示，提供"继续游戏"、"返回主菜单" | Pause |
| **StageTipsLayer.hpp** / **StageTipsLayer.cpp** | 关卡提示层，每关开始时显示目标金额和关卡号 | StageTipsLayer |
| **Gold.hpp** / **Gold.cpp** | 旧版金矿实现（已被Mineral.hpp替代，保留参考） | Gold |

**Game.hpp关键功能（重要！）：**
- `InputMode`枚举：TOUCH（触摸）/ OPENCV（本地手势）/ AI（云端AI）三种输入模式
- 物理碰撞检测：`physicsBegin()`钩子抓矿
- 手势回调处理：`onGestureData()`
- 时间倒计时：`updateTime()`
- 钩子摇摆动画：`startShakeHookAnimation()`

### 1.2 gameobjects/ - 游戏对象类

| 文件 | 功能说明 | 核心类 |
|------|---------|--------|

**Mineral.hpp矿物类型：**
```cpp
enum class Type {
    GOLD_SMALL,    // 小金块（价值200）
    GOLD_MEDIUM,   // 中金块
    GOLD_LARGE,    // 大金块（价值500）
    STONE_SMALL,   // 小石头（价值低但重）
    STONE_MEDIUM,  // 中石头
    STONE_LARGE,   // 大石头
    DIAMOND,       // 钻石（价值高，重量轻！）
    TREASURE_BAG   // 宝藏袋
};
```

### 1.3 services/ - 服务层（业务逻辑）

| 文件 | 功能说明 | 核心类/接口 |
|------|---------|------------|
| **IGestureRecognizer.hpp** | 🎯**关键！**手势识别抽象接口，定义统一的识别器API | IGestureRecognizer（纯虚接口） |
| **LocalGestureRecognizer.hpp** / **.cpp** | 本地OpenCV手势识别器，基于颜色分割+轮廓检测 | LocalGestureRecognizer |
| **CloudGestureRecognizer.hpp** / **.cpp** | 云端AI手势识别器，通过HTTP调用API | CloudGestureRecognizer |
| **AIGestureService.hpp** / **.cpp** | AI手势识别服务的高级封装 | AIGestureService |
| **GestureFusion.hpp** / **.cpp** | 多识别器融合器，同时使用本地+云端，取置信度高的结果 | GestureFusion |
| **GestureClient.hpp** / **.cpp** | 手势识别客户端，连接GestureServer服务 | GestureClient（单例） |
| **GestureRecognizer.hpp** / **.cpp** | 旧版手势识别器（保留参考） | GestureRecognizer |
| **GestureData.hpp** | 手势数据结构定义 | GestureData, GestureResult |
| **PlayerManager.hpp** / **.cpp** | 玩家档案管理（单例），支持创建/选择玩家、保存历史记录 | PlayerManager（单例） |
| **LevelLoader.hpp** / **.cpp** | 关卡数据加载器，从JSON读取关卡配置 | LevelLoader（单例） |

**IGestureRecognizer接口设计（重要！）：**
```cpp
class IGestureRecognizer {
    virtual bool start() = 0;          // 启动识别器
    virtual void stop() = 0;           // 停止识别器
    virtual void pushFrame(...) = 0;   // 推送一帧图像
    virtual void setCallback(...) = 0; // 设置回调
};
```
→ **策略模式的典型应用！**
