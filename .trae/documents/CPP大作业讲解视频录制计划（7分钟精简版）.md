## 【架构揭秘】1:30-2:45 ⏱️

### 代码结构（30秒，快闪过）

```
Classes/
├── MainScene/      # 游戏主场景（Game.hpp）
├── gameobjects/    # 矿物（Mineral.hpp）
├── services/      # 手势识别（GestureClient.hpp）
└── Other/         # 数据管理（UserDataManager.hpp）
```

> "就这么几个文件夹，别怕！**比你宿舍的衣柜还简单**。"

### 核心类 - Game.hpp（45秒，重点讲）

```cpp
enum class InputMode { TOUCH, OPENCV, AI };  // 三种输入模式
```

> "这是什么？**强类型枚举**！比普通枚举更安全，不会有数字乱飞的问题。"

```cpp
bool isOpenHook;        // 钩子是不是"张开"的
bool ropeChangeing;     // 绳子是不是在伸缩
int ropeHeight;         // 绳子有多长
```

> "看这三个变量，**游戏的所有状态都在这儿了**。isOpenHook是false？好，钩子正在摇摆。isOpenHook变true？说明抓到东西了，绳子要往回拉了！"

### 手势识别 - GestureClient.hpp（45秒，重点讲）

```cpp
std::thread _thread;                    // 独立线程跑OpenCV
std::atomic<bool> _running{false};     // 线程开关
std::mutex _frameMutex;                // 保护共享数据
```

> "这里用了**C++11的多线程**。为什么要开线程？因为OpenCV处理摄像头很慢，如果放在主线程，游戏就卡成PPT了！"
>
> "_running用atomic是因为...它要在两个线程之间共享。mutex？**锁住frame数据**，不然你会看到摄像头画面抽搐得像在跳广场舞。"

## 【趣味演示】2:45-4:00 ⏱️

### 最小知识点的最大快乐（45秒）

**讲单例模式 - UserDataManager**

```cpp
static UserDataManager* getInstance() {
    if (_instance == nullptr) {
        _instance = new UserDataManager();
    }
    return _instance;
}
```

> "这叫什么？**单例模式**！就像厕所的纸巾盒——所有人都用同一个实例，**谁也别想独占**！"
>
> "游戏里只有一个UserDataManager，记录你的金币和关卡。要是整出来两个，金币不得翻倍？**经济系统直接崩盘**！"

**讲回调函数 - Lambda表达式**

```cpp
startBtn->addTouchEventListener([=](Ref *sender, Widget::TouchEventType type) {
    if (type == Widget::TouchEventType::ENDED) {
        // 处理点击
    }
});
```

> "这个**[=]**是什么意思？**捕获所有变量**！就像你去超市，购物车=把所有东西都装进来。"
>
> "好处是什么？**一行代码搞定回调**，不用单独写个函数，代码简洁得像诗！"

## 【C++特性秀】4:00-5:30 ⏱️

### 快速过一遍亮点（90秒）

| C++特性 | 代码位置 | 一句话解释 |
|---------|---------|-----------|
| **强类型枚举** | InputMode | "比普通枚举**更安全**，编译器帮你纠错" |
| **多线程** | GestureClient | "OpenCV跑后台，**游戏不卡顿**" |
| **atomic/mutex** | 数据同步 | "**线程安全三剑客**：atomic做标记，mutex做保护" |
| **std::function** | 回调机制 | "**万能回调容器**，什么都能往里装" |
| **std::move** | 避免拷贝 | "**转移所有权**，不浪费内存" |
| **Lambda** | 事件监听 | "**匿名函数**，代码更简洁" |
| **auto** | 类型推断 | "**让编译器猜类型**，少打字" |

> "这些特性在C++11/17里都是**标配**，面试必问！学会了就是**简历加分项**！"

## 【踩坑回忆】5:30-6:15 ⏱️

### 我的血泪史（45秒）

**坑1：内存泄漏**
> "第一次写的时候，我new了一堆矿物对象，切换场景忘了delete。跑起来内存直接爆了！后来学会用**Cocos2d-x的autorelease**，再也没这问题。"

**坑2：摄像头卡顿**
> "最开始把OpenCV放主线程，结果游戏一秒卡成三帧。后来改成**独立线程+mutex**，丝滑得像德芙！"

**坑3：跨平台**
> "Windows用命名管道，Mac/Linux不支持。后来抽象出**GestureClient接口**，支持PIPE和HTTP两种模式，**兼容所有平台**！"
