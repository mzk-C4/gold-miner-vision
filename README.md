# 🌟 黄金矿工 - 手势识别版

🎮 经典黄金矿工游戏的现代化重构，支持**手势控制**和**AI视觉识别**，带来全新的游戏体验！

## 🚀 技术栈

| 分类 | 技术 | 版本 |
|------|------|------|
| **游戏引擎** | Cocos2d-x | 4.0 |
| **手势识别** | OpenCV | 4.5.5 |
| **AI视觉** | 云端API | - |
| **构建工具** | CMake | 3.16+ |
| **语言** | C++ | C++17 |

## ✨ 特色功能

### 🤚 手势控制
- **手部倾斜** → 控制钩子摇摆方向（-65° ~ +65°）
- **手掌张开** → 释放钩子
- **握拳** → 加速回收
- **点赞手势** → 触发炸弹

### 🎯 双模式识别
- **本地CV模式**: OpenCV颜色阈值识别，使用彩色手套
- **云端AI模式**: 高精度手势识别API
- **键盘兜底**: 传统按键操作

### 🛒 商店系统
- 💣 **炸药**: 炸毁重物节省时间
- 💪 **力量药水**: 提升钩子拉力
- 💎 **钻石升值书**: 钻石价值翻倍
- 📚 **矿石收藏书**: 石头也能卖钱

### 🎵 音乐系统
- 支持背景音乐切换
- 内置周杰伦、陶喆经典歌曲库

## 📁 项目结构

```
cocos2d-proj/
├── Classes/           # 游戏核心代码
│   ├── MainScene/     # 场景（游戏、商店、菜单）
│   ├── gameobjects/   # 游戏对象（矿物、钩子）
│   ├── services/      # 服务层（手势、玩家管理）
│   └── Other/         # 工具类
├── Resources/         # 资源文件
│   ├── music/         # 音效与背景音乐
│   └── *.csb          # CocosStudio布局
└── GestureServer/     # 手势识别服务端
```

## 🛠️ 构建说明

### 环境要求
- Cocos2d-x 4.0+
- OpenCV 4.5.5 (`F:\toolbox\opencv`)
- Visual Studio 2019+ / MinGW

### 构建步骤
```bash
cd cocos2d-proj
mkdir build && cd build
cmake ..
cmake --build . --config Release
```

## 🎮 游戏操作

### 手势控制
| 手势 | 操作 |
|------|------|
| 手掌张开 | 释放钩子 |
| 握拳 | 加速回收 |
| 左右倾斜 | 控制方向 |
| 点赞 | 使用炸弹 |

### 键盘控制（兜底）
| 按键 | 功能 |
|------|------|
| 空格 | 释放钩子 |
| B | 使用炸弹 |
| Esc | 暂停 |

## 🏆 项目亮点

- **C++设计模式**: 单例、策略模式、观察者模式
- **接口抽象**: `IGestureRecognizer` 统一手势识别接口
- **多模式融合**: 本地CV + 云端AI双模式自动切换
- **数据持久化**: 玩家档案、关卡进度管理
