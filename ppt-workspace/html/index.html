四大核心技术突破

INNOVATION · DUAL-ENGINE + GESTURE-AS-COMMAND + ASYNC + DEBOUNCE

从架构设计到算法实现，多维度技术创新体现现代 C++ 工程开发深度
🔀
双引擎融合架构
LOCAL + CLOUD COLLABORATIVE
创新性地将本地 OpenCV 高频识别与云端 AI 精确校验融合为协同体系。OPEN_PALM 模式下本地引擎每 30ms 驱动角度，FIST 触发后云端二次确认——兼顾实时性与准确性。云端不可用时自动降级，系统鲁棒性不受影响。
双识别器并行 安全优先策略 自动降级回退 置信度加权融合
🤚
手势即指令
GESTURE-AS-COMMAND PARADIGM
摒弃传统键盘鼠标中介，建立从手势语义到游戏操作的直接映射管道：张开手掌→瞄准 (OPEN_PALM→targetAngle)，握拳→释放(FIST→shouldReleaseHook)，长握 1.5s→引爆(BOMB_HOLD→shouldDetonateBomb)，左右倾斜手掌控制钩子偏转角。配合键盘兜底模式保证可玩性。
四种手势指令 键盘智能兜底 自然交互范式 无硬件依赖
⚡
异步非阻塞架构
ASYNC + NON-BLOCKING DESIGN
识别线程与游戏 35FPS 主循环完全解耦。帧推送（pushFrame）即时返回，识别结果通过 ResultCallback 异步回调通知。使用 std::atomic 保证跨线程数据访问安全，零互斥锁设计避免主线程等待。云端 HTTP 请求同样异步，不会阻塞本地高频识别。
std::atomic 无锁 std::function 回调 零互斥锁设计 智能指针管理
🔒
状态机去抖设计
FSM + EMA TEMPORAL FILTERING
手势状态管理采用有限状态机 (FSM) 建模：IDLE → AIMING → LOCKED → RELEASED。配合EMA 时域滤波消除单帧识别抖动——手势需连续 ≥3 帧一致才切换，角度增量限幅 ≤5°/帧。COOLDOWN (0.8s) 防连击，BOMB_HOLD (1.5s) 区分释放/引爆意图，实现工程级稳健性。
FSM 状态建模 EMA 指数平滑 0.8s 冷却防连击 1.5s 长握引爆
