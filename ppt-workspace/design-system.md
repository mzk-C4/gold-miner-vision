# 黄金矿工-手势识别版 视觉系统

## 视觉气质
深色科技感 + 金色矿工主题。像一个精心设计的精品 Keynote：深蓝黑底色、暖金点缀、纸质纹理、微妙阴影。有游戏趣味但不幼稚，专业但不冰冷。

## 画面比例
- 16:9（1920x1080）
- 安全边距：左右 100px，顶部 80px，底部 60px

## 色彩（自然降饱和版）

| 颜色 | 色值 | 角色 |
|------|------|------|
| 深蓝黑 | #0A0E27 | 主背景 |
| 深蓝灰 | #1E2340 | 卡片/区域背景 |
| 暖金 | #D4A843 | 主强调、标题高亮、矿物元素 |
| 钢蓝 | #4A7FB5 | 科技感、链接、数据流 |
| 薄荷绿 | #5BAF8A | 成功、通过、算法正确 |
| 柔紫 | #7B6BA0 | 云端/远程标注 |
| 暗玫瑰 | #C57B8A | 警告/冲突路径 |
| 浅灰 | #8A8FA8 | 辅助文字、注释 |
| 白色 | #E8E8EC | 正文、代码、图标（微暖白，非纯白） |

> 与旧版 (#FFD700/#00B4FF/#00FFB2) 相比，新版颜色降饱和 20-30%，更像印刷品和真实材质，避免 AI 生图的霓虹味。

## 字体方向
- 中文标题：粗黑体、大号、金色或白色
- 英文术语：等宽体、亮蓝或薄荷绿
- 数据/代码：等宽体、亮色
- 标签：贴纸式短标签，2-5 字

## 页面结构
- 顶部：简洁标题栏，左侧页标题，右侧小图标
- 主体：内容区域，居中或左右分栏
- 底部：极小页码（可选）

## 版式变体
1. **封面大视觉**：大标题 + 钩子/手势主视觉
2. **双栏对比页**：左右分栏展示对比
3. **流程页**：横向或纵向步骤流
4. **代码/数据结构页**：中央代码框 + 周围注释标签
5. **表格页**：2-4 行简洁表格
6. **三卡亮点页**：3 个大卡片，每个一个亮点
7. **路线图页**：阶段性展示

## 图像风格
- 扁平科技风 + 微 3D 质感
- 矿物、钩子、手势图标用金色和亮蓝
- 背景有微弱网格或电路纹理
- 数据流用发光线条表示
- 不要卡通、不要写实、不要暗黑恐怖

## 负面约束
- 不要白底商务风
- 不要游戏 UI 截图风格
- 不要大段中文小字
- 不要复杂的真实图表
- 不要渐变紫色主色调
- 不要出现随机乱码或伪代码
- 不要让装饰遮挡主标题
