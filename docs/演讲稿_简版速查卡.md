## 核心金句（背下来）

1. "整个手势识别是 5 步流水线：**HSV 分割 → 轮廓检测 → 凸包分析 → 指尖识别 → 角度计算**，每步 3-8 毫秒，加起来 **30 毫秒处理一帧**"

2. "双引擎融合的核心思想是**快慢结合**：本地 OpenCV 每 30ms 高频响应，云端 AI 只在握拳时做**精准确认**"

3. "std::atomic 是 C++ 多线程编程的基石——**不需要加锁就能安全共享数据**，性能远高于 mutex"

4. "RAII 是 C++ 最独特的设计哲学：**资源生命周期 = 对象生命周期**，绝不泄露"

5. "分层架构的好处：**改一层，其他层不用动**。想换识别算法？加新类就行，游戏逻辑一行不改"

## 如果只记住三件事

1. **怎么做到的**：5 步 OpenCV 流水线，HSV 提取肤色，凸包找指尖，EMA 平滑角度
2. **为什么这么设计**：本地快(30ms) + 云端准(按需) = 快慢互补，安全降级
3. **学到了什么**：纯虚接口、原子操作、RAII、分层架构、三种设计模式
